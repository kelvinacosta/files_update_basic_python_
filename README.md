# How to updaload files using Python

This repository contains the activity for learning purposes 

## Description 

This activity is created for learning purposes. This project demonstrates how to manage and update a list of allowed IP addresses using Python.  
It includes methods to **read**, **write**, and **modify files** in a secure and organized way.  
This is a learning project and is used for educational purposes.


## Features

- Open and read a file containing allowed IP addresses.
- Convert file contents into a list for easy manipulation.
- Remove unwanted IP addresses using a `remove_list`.
- Update the file with the revised list while keeping it clean and organized.


## Requirements
Basic understanding of Python and Cyber Security.
